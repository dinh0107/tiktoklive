Music cho OBS

Phát YouTube / SoundCloud trong Browser Source. OBS lấy tiếng livestream; tắt Monitor để không phát ra loa máy.

Chưa có bài.

Cấu hình OBS (quan trọng)
  1. Thêm Browser Source → URL …
  2. Width ~800, Height ~450 (có thể kéo source ra ngoài khung hình).
  3. Advanced Audio Properties → nguồn Browser này → Audio Monitoring = Monitor Off (stream vẫn có tiếng, loa máy im).
  4. Đừng mute nguồn này trên mixer. Nếu dùng Desktop Audio, tắt/mute Desktop để khỏi bị đôi tiếng.
